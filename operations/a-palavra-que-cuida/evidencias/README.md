# Evidencias do canal

Este diretorio contem registros atomicos. Cada afirmacao factual usa uma fonte
individual. Decisoes humanas e hipoteses permanecem classificadas como tal.

O arquivo `claims-v1.jsonl` e append-only durante a fase piloto. Uma decisao
nova nao reescreve a evidencia antiga; ela recebe outro identificador e aponta
para o que substitui quando necessario.
