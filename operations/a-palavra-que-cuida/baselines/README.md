# Baselines da operação

Nenhuma baseline está aprovada nesta operação em 2026-07-26. Isso é
intencional: os vídeos produzidos fornecem evidência e dívida conhecida, mas não
demonstram repetibilidade limpa das capacidades críticas.

Quando uma capacidade puder ser estabilizada, registre aqui um JSON validado por
`Baseline.schema.json`. Ele deve declarar condições, parâmetros rastreados,
evidências, testes, gate humano, execuções limpas e a regra que invalida a
comparação. Uma alteração em parâmetro rastreado exige revalidação; não se deve
editar uma baseline anterior para fazê-la parecer compatível.
